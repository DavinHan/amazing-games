# Walker · 第一阶段开发目标

状态：目标与 [Windows 技术设计](technical-design.md) 已整理，以下开发项和体验验收均未执行。目标平台为 Windows 11 x64，采用 UE 5.8.4 方案；工程创建与运行验证均在 Windows 上进行。

## 阶段成果

交付一个可以实际操作的 3D 行走小样：一名身形高挑、丰满的成年女性角色穿着高跟鞋，在简单场景中通过 WASD 行走，手脚协调，并可通过 V 键在背后第三人称和第一人称之间切换。

本阶段重点验证角色外观、步态、方向控制与相机体验。占位模型可以用于早期技术验证，最终验收应使用符合外观要求的角色和高跟鞋。

## 功能目标

### 角色与场景

- 角色具有清晰可辨的高挑身形与丰满体态；具体身高、比例、服装和美术风格在资源选型时确定。
- 高跟鞋有可辨认的鞋跟和鞋型，站立与行走姿态与穿高跟鞋的状态匹配。
- 提供平坦地面、适当光照和空间参照，便于判断位移、落脚和身体动作。
- 角色与地面关系稳定，脚部和鞋跟没有明显穿地、悬浮或抖动。

### 方向控制

| 输入 | 预期表现 |
| --- | --- |
| 按住 `W` | 持续向前行走 |
| 按住 `A` | 持续向左平移 |
| 按住 `S` | 持续向后行走 |
| 按住 `D` | 持续向右平移 |
| 松开所有移动键 | 停止位移，平滑回到站立状态 |

以下为第一阶段技术设计采用的规则，尚未实现验证：

- 前后左右以角色自身朝向在地面上的方向为基准。
- A/D 是平移，角色不自动转身；S 是后退，角色不转身向前走。
- 组合方向键允许斜向移动，斜向总速度与单方向一致。
- 相反方向输入互相抵消，例如 W+S 不产生前后位移，A+D 不产生左右位移。
- 角色速度与渲染帧率解耦；应用失焦时清除移动输入，避免切回后持续行走。
- 失焦立即停止；恢复焦点后等待移动、切换和复位键全部松开，再接受新操作。
- 按 R 恢复出生位置、朝向、站立动画和默认第三人称视角；按 Esc 退出独立程序。

### 手脚协同步态

- 双腿交替迈步，步幅、步频与实际位移速度匹配，避免明显滑步。
- 双臂与腿部动作协调；前进时体现左腿与右臂、右腿与左臂的交替配合，摆幅自然。
- 身体和髋部随步伐适度调整，整体姿态稳定，体现高跟鞋行走的支撑与重心变化。
- 后退、左平移和右平移的脚步方向与实际位移一致，不能只把前进动作原样套在所有方向上。
- 四个斜向同样需要匹配实际移动方向和支撑姿态；基本方向混合无法达标时补充斜向动作。
- 起步、停止和改变方向时动作连续，避免瞬间跳姿、肢体错位或明显穿插。
- 采用目标骨架的原地循环动画、动画蓝图和 2D Blend Space；外来动作在编辑期重定向并修正，具体资源和是否需要少量足部 IK 修正由 W1 验证确定。

### 视角切换

- 启动后默认位于角色背后的第三人称视角，能观察全身及脚部动作，镜头随角色移动。
- 按一次 V 切到角色眼睛附近的第一人称视角，视线朝向与角色朝向一致。
- 再按一次 V 返回背后第三人称视角。
- 每次独立按下 V 只切换一次；长按不因按键重复事件连续切换。
- 切换过程中保持角色位置、朝向和输入状态，步态继续播放，不重置角色或动画。
- 两种视角下的 WASD 含义一致，不因相机位置改变而反转方向。
- 第一人称避免头部、头发或其他自身模型遮挡视线，镜头保持可用和稳定。
- 第一阶段固定角色朝向，不加入鼠标环视或转向输入；第一人称使用稳定眼高，隐藏整个人物及附属模型，动画持续更新。
- V 采用瞬时切换，避免镜头穿过头部；第三人称完整显示身体和鞋部。
- 在可行走区域四边和四个角落，第三人称及从第一人称切回后仍能看到全身与鞋跟；通过角色边界与外侧遮挡物之间的相机缓冲区保证构图，并保留镜头碰撞保护。

## 开发清单

按依赖顺序推进；每项完成后记录验证结果。

- [ ] **W1a · Windows 工具链验证**：按技术设计建立 UE 5.8.4 工程，验证源码编译、空场景与 Windows 独立打包运行，记录完整环境版本。
- [ ] **W1b · 角色与资源验证**：确认候选角色、高跟鞋、模型与动画来源和授权；验证站立、四基向与四斜向动作，标定速度和接地，记录目标设备与性能；确定资源集合和是否需要足部修正。
- [ ] **W2 · 场景与角色**：建立简单地面与光照场景，放入符合体态和高跟鞋要求的角色，验证站立姿态；分开设置角色碰撞边界与外侧围栏，预留并记录相机缓冲空间。
- [ ] **W3 · 方向控制**：实现四方向位移、停止、组合输入、失焦清理、复位和退出，验证侧移和后退保持朝向；配置 `GameViewportClientClassName`，确认 Development 独立包实际启用自定义 ViewportClient 并执行焦点回调。
- [ ] **W4 · 步态协同**：接入站立、前进、后退、侧移及斜向动作，调整手脚配合、落脚和动作衔接。
- [ ] **W5 · 相机**：实现背后跟随相机、第一人称相机及 V 键切换，验证移动状态连续性；在四边、四角及第一人称切回时检查全身构图，标定相机缓冲距离。
- [ ] **W6 · Windows 集成验收**：对 Development 和 Shipping 独立包执行下表检查，记录问题与结果，并在项目 README 中补充实际运行与验证方式。
