# Walker

一个以女性角色穿高跟鞋行走为主题的 3D 交互小样，验证方向控制、协调步态与第一、第三人称视角切换。

## 第一阶段目标

- 展示一名身形高挑、丰满的成年女性角色，穿着高跟鞋。
- 通过 `W`、`A`、`S`、`D` 分别控制前进、向左平移、后退、向右平移。
- 行走时双腿交替迈步，双臂与步伐自然协同；前进、后退、侧移均有匹配的动作表现。
- 默认使用角色背后的第三人称视角，能观察角色全身与高跟鞋步态。
- 按一次 `V` 切换到第一人称视角，再按一次 `V` 返回第三人称视角。
- 在简单、光照清晰的地面场景中完成移动、停止及反复切换视角的体验。

本阶段定位为动作展示小样，验收围绕角色、控制、动画与相机展开。

详细需求与验收方法见 [第一阶段开发目标](docs/phase-1.md)；架构、资源契约、实现算法、Windows 工具链和打包流程见 [Windows 技术设计](docs/technical-design.md)。

## 操作方式

| 按键 | 动作 |
| --- | --- |
| `W` | 前进 |
| `A` | 向左平移 |
| `S` | 后退 |
| `D` | 向右平移 |
| `V` | 第一人称与背后第三人称之间切换 |
| `R` | 复位到出生位置、站立状态和第三人称视角 |
| `Esc` | 退出独立程序 |
| 松开移动键 | 停止移动并回到站立状态 |

第一阶段设计采用角色自身朝向作为方向基准；侧移、后退和视角切换保持朝向不变，不加入鼠标环视或转向。第一人称使用稳定眼高并隐藏自身模型；返回第三人称恢复显示。应用失焦立即停止，恢复焦点后先松开移动、切换与复位键，再重新操作。以上均为待实现、待验收行为。
